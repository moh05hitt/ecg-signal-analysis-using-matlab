Real-Time ECG Signal Analysis Using MATLAB and ESP32

Overview

A real-time ECG monitoring system developed using MATLAB and ESP32. The system acquires ECG signals, filters noise, detects R-peaks, calculates heart rate, analyzes heart conditions, and generates ECG reports.

Features

- Real-time ECG signal acquisition
- Live waveform visualization
- Signal filtering
- R-peak detection
- Heart Rate (BPM) calculation
- Bradycardia/Tachycardia detection
- Rhythm analysis (Regular/Irregular)
- Signal quality assessment
- Automatic report generation
- ESP32 alert communication

Technologies Used

1. MATLAB
2. ESP32
3. ECG Sensor
4. Serial Communication

Output

- Heart Rate (BPM)
- Heart Condition
- Rhythm Status
- Signal Quality
- ECG Analysis Report
